# SF Wedding

A single-page, red-thread wedding invitation for Sebastian and Flemy — engagement Jan 4 2027 (Calicut),
wedding Jan 9 2027 (Ernakulam). Built with Next.js (App Router, TypeScript, static export), Tailwind CSS,
and Framer Motion.

Full project docs — scope, build order, and design system — live in `.claude/docs/`:

- `.claude/docs/PROJECT.md` — what the site is and why.
- `.claude/docs/IMPLEMENTATION-PLAN.md` — build order, phases, and gates.
- `.claude/docs/DESIGN.md` — tokens, foundations, and components.

The previous static-HTML build is archived at [`legacy-html/`](legacy-html/), reference-only.

## Development

```bash
npm run dev     # start the dev server
npm run build   # production static export
npm run lint    # lint
```
